## What an agent should know first

Chemius markets seven APIs and publishes a reference for none of them. Every per-API page ends at
"Book a call & ask for the API documentation". There is no OpenAPI, no AsyncAPI, no GraphQL SDL, no
WSDL, no Postman collection, no SDK in any registry, no MCP server, no agent card, and no
/.well-known/ document on any Chemius host. An agent cannot call a Chemius API today, and cannot
learn how to from any public source. Access is a commercial motion: buy a paid plan, request the
add-on, take the call.

## The APIs

- Safety Data Sheet API (SDS API): https://www.chemius.net/safety-data-sheet-api/
  Returns permanent Chemius permalinks for SDSs so an ERP/CRM stores a link once instead of a PDF.
  A daily poll identifies which products have changed SDSs, driving the REACH customer
  re-notification duty.
- Technical Data Sheet API (TDS API): https://www.chemius.net/technical-data-sheet-api-tds-api/
  Retrieves TDS sections by purpose and language, returning layout plus formatted content and rich
  media, with Chemius styling that the integrating site may override.
- ADR API: https://www.chemius.net/adr-api/
  Receives a product list and quantities, calculates ADR points server-side and returns a
  ready-to-print dangerous-goods transport document as PDF. ADR rule changes are applied inside
  Chemius, so the caller's ERP holds no rule version.
- Web Shop API: https://www.chemius.net/web-shop-api/
  Pushes the mandatory hazard text a web shop must display for each hazardous chemical.
- Label API: https://www.chemius.net/label-api/
  Delivers structured multilingual labelling content to labelling software or an ERP.
- ERP API: https://www.chemius.net/erp-api/
  Synchronises hazard data (H and P phrases, pictograms), physical/chemical properties and
  transport data (UN numbers, labels, classes) into an ERP.
- PDF API: https://www.chemius.net/pdf-api/
  Generates and serves always-current PDF renderings of SDS, TDS and Safety Instructions.
